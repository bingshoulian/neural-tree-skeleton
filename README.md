## 快速开始（3 分钟上手）

### 1. 先看示例

打开 `验证脚本/demo_tree.md`，5 分钟看完，你就知道一棵神经树长什么样。

### 2. 创建你的第一棵树

**流程**：建树 → 增神经元 → 建突触 → 验收

```
① 复制 01_通用神经树模板.md 为 神经树_《你的领域》_v1.0.md
② 填写根（一句话本质 + 3 判断题），确定领域架构
③ 按 11 元素标准填写第一个神经元（N1）
④ 添加触发词（精确词在前，模糊词在后，用 // 分层）
⑤ 出处标注可信度（L1=权威来源 / L2=有依据 / L3=经验）
⑥ 写完 3-5 个神经元后，建立树内突触
⑦ 查全域索引表，建跨树突触
⑧ 跑自检清单 → 跑验证脚本
```

### 3. 验证

> 对应 SKILL.md 第 2.6 节：`神经树 验证 <树名或文件路径>`

```bash
python "验证脚本/神经树验证器.py" "神经树_《你的领域》_v1.0.md"
```

## 核心概念（30 秒速览）

```
神经树 = 一个知识领域的完整知识体系文件
神经元 = 单个知识决策节点（11 个标准元素）
突触   = 神经元之间的关联连接
末梢   = 可现场执行的动作清单
全域索引表 = 所有树的导航 + 触发词倒排索引
```

**11 元素标准**：定义 → 场景 → 适用主体与范围 → 数据 → 触发词 → 标签 → 判定模板 → 误判防御 → 检查清单 → 突触 → 出处
