## 🌱 根（Root）：一句话穿透本质

> **合同解除 = 让一个有效合同提前结束的法律工具——不是违约惩罚，而是"双方/单方不想继续了怎么办"的退出机制。**

**3 个判断题验证**：
1. **第一性原理**：合同解除不是惩罚违约者，是解决"合同没必要继续"的问题
2. **反过来说还对吗**："合同解除是惩罚违约者"——不对，解除后的赔偿才是惩罚，解除本身是中立状态变更
3. **1 句话讲给外行听**："签了合同后发现不合适，怎么合法地说不干了，以及干了之后要收拾什么烂摊子"

## 🌿 主干2：解除后果

### 🧠 N3 · 解除后的法律后果

| 元素 | 内容 |
|------|------|
| **① 一句话定义** | 合同解除＝未履行的部分终止履行，已履行的可要求恢复原状或补救，同时可以索赔——解除不清空责任 |
| **② 使用场景** | 解除生效后进行清算、退还、赔偿安排时 |
| **③ 适用主体与范围** | 【原文】未限定（源文未设主体门槛）：合同双方当事人均可行使返还、补救与赔偿请求权 |
| **④ 核心数据/要点** | 【原文】§566①：合同解除后，尚未履行的终止履行；已经履行的，根据履行情况和合同性质，当事人可以请求恢复原状或者采取其他补救措施，并有权请求赔偿损失。§566②：合同因违约解除的，解除权人可以请求违约方承担违约责任，但是当事人另有约定的除外 |
| **⑤ 触发词** | `恢复原状|返还|§566 // 终止履行|补救措施|赔偿损失|清算` |
| **⑥ 标签** | `#合同法/解除后果` |
| **⑦ 判定模板** | 模式A（线性）：①区分已履行/未履行部分→②未履行的终止履行→③已履行的按履行情况和合同性质选恢复原状或其他补救→④主张赔偿损失→⑤因违约解除的，同时主张违约责任 |
| **⑧ 误判防御** | ①"解除＝自始全部作废、一律互相返还"——恢复原状须"根据履行情况和合同性质"，继续性合同通常不溯及既往 ②"解除了就不能再要违约金"——错，§566②明确可并主张 ③"返还只退本金"——【操作口径】赔偿范围可含资金占用损失 |
| **⑨ 检查清单** | □已履行/未履行已区分？□恢复原状还是折价补救已确定？□损失赔偿与违约责任已主张？ |

| **⑭ 罚则** | 无（后果分配规则） |

### 🧠 N4 · 任意解除权（一般解除规则的例外）

| 元素 | 内容 |
|------|------|
| **① 一句话定义** | 无需违约事由、也无需约定条件，特定主体依法可"随时"解除合同——但要赔钱 |
| **② 使用场景** | 处理承揽、委托、不定期租赁等继续性合同的退出请求时 |
| **③ 适用主体与范围** | 【原文】仅限法定类型的特定主体：承揽合同的定作人（§787）、委托合同的双方当事人（§933）、不定期租赁的双方（§730，应在合理期限之前通知）。【操作口径】任意解除权可否由当事人约定排除或限制，法无明文，实务存在分歧。排除：买卖等一时性合同不适用任意解除权 |
| **④ 核心数据/要点** | 【原文】§787：定作人在承揽人完成工作前可以随时解除合同，造成承揽人损失的，应当赔偿损失；§933：委托人或受托人可以随时解除委托合同，因解除造成对方损失的，除不可归责于该当事人的事由外，无偿委托的解除方赔偿因解除时间不当造成的直接损失，有偿委托的解除方赔偿对方的直接损失和合同履行后可以获得的利益 |
| **⑤ 触发词** | `任意解除|随时解除|§787|§933 // 定作人|委托合同|不定期租赁|赔偿损失` |
| **⑥ 标签** | `#合同法/任意解除权` |
| **⑦ 判定模板** | 模式A（线性）：①识别合同类型（承揽/委托/不定期租赁）→②确认请求方是否法定任意解除主体→③检查是否处于可行使阶段（承揽：完成工作前）→④决定行使并通知（→N2）→⑤测算并赔偿对方损失 |
| **⑧ 误判防御** | ①"任意解除＝随便解不担责"——错，造成损失须赔偿 ②"什么合同都能随时解"——仅限法定类型与法定主体 ③"约定排除任意解除权一律无效"——【操作口径】效力存在争议，通说允许委托合同约定排除或限制，个案须检索裁判口径确认 |
| **⑨ 检查清单** | □合同类型属于法定可任意解除范围？□行使主体是否适格？□对方损失赔偿已测算？ |

## 🌿 主干3：救济措施

### 🧠 N5 · 解除与违约赔偿的关系

| 元素 | 内容 |
|------|------|
| **① 一句话定义** | 解除与赔偿不是二选一：因违约解除合同的，解除权人既可以解除、又可以同时要求违约方担责 |
| **② 使用场景** | 对方违约，既想解除又想索赔时的方案设计 |
| **③ 适用主体与范围** | 【原文】未限定（源文未设主体门槛）：解除权人均可同时主张解除与违约责任；排除：当事人另有约定的从其约定（§566②但书） |
| **④ 核心数据/要点** | 【原文】§566②：合同因违约解除的，解除权人可以请求违约方承担违约责任，但是当事人另有约定的除外；§577：当事人一方不履行合同义务或者履行合同义务不符合约定的，应当承担继续履行、采取补救措施或者赔偿损失等违约责任。【操作口径】解除后的赔偿可主张履行利益（可得利益），以§584可预见性规则为限 |
| **⑤ 触发词** | `违约赔偿|违约责任|§577 // §584|可得利益|可预见|违约金|损失赔偿` |
| **⑥ 标签** | `#合同法/违约赔偿` |
| **⑦ 判定模板** | 模式A（线性）：①确认对方构成违约→②决定解除（→N1/N2）→③固定损失证据→④主张恢复原状/补救（→N3）+赔偿损失→⑤有违约金条款的，主张违约金并与实际损失比对 |
| **⑧ 误判防御** | ①"解除了就不能要违约金"——错，违约责任照担 ②"违约金和损害赔偿可以双份拿"——【操作口径】不能重复获利，实务通常择一从高、以实际损失为基准调整 ③"赔偿只算直接损失"——履行利益范围内的可得利益也可主张（以§584可预见性为限） |

### 🧠 N6 · 解除权消灭

| 元素 | 内容 |
|------|------|
| **① 一句话定义** | 解除权不是永久的——过期不用、放弃行使、履行完毕三种情况都会让解除权消失 |
| **② 使用场景** | 判断解除权是否还"活着"时；对方很久前违约现在想解除是否可行 |
| **③ 适用主体与范围** | 【原文】各类民事合同的解除权（约定解除权与法定解除权）均适用除斥期间规则；排除：不适用于请求权（诉讼时效制度另行处理，除斥期间不发生中止、中断） |
| **④ 核心数据/要点** | 【原文】§564：法律规定或者当事人约定解除权行使期限，期限届满当事人不行使的，该权利消灭；法律没有规定或者当事人没有约定解除权行使期限的，自解除权人知道或者应当知道解除事由之日起一年内不行使，或者经对方催告后在合理期限内不行使的，该权利消灭。【操作口径】解除权属形成权，除斥期间为不变期间，不发生中止、中断；解除权人明确表示放弃的，权利亦消灭（学理通说）。【操作口径】"合理期限"实务常参照催告后90日左右掌握。⚠️待核："合理期限"的统一认定标准｜待最高院合同编通则司法解释适用口径/类案确认 |
| **⑤ 触发词** | `解除权消灭|§564 // 除斥期间|合理期限|放弃解除权|过期|催告` |
| **⑥ 标签** | `#合同法/解除权` |

## 🧬 综合论述（Thesis）：合同解除的决策链路

**论题**：从"想解除合同"到"完成解除"，需要过五关判断：类型→程序→后果→赔偿→时效。

**涉及神经元**：→N1 →N2 →N3 →N5 →N6

**分析**：
收到解除需求时，第一关判断是否有解除权（N1：约定/法定）；第二关走通知程序（N2：通知→异议期→生效）；第三关计算解除后的返还和赔偿（N3+N5：恢复原状+损失赔偿）；最后别忘了检查解除权是否已过期（N6：除斥期间）。

五关缺一不可——漏了程序关可能让对方有机会异议，漏了时效关可能发现解除权已经消灭。

**结论**：建议做成一张"合同解除五步判定卡"，贴在每个末梢前面。

## 🍃 末梢区

### 末梢1：发出解除通知前自查

| 字段 | 内容 |
|------|------|
| **触发词** | `解除通知|发通知|要解除|怎么解除` |
| **动作** | ①确认有解除权（约定/法定）→②写书面解除通知→③写明解除理由+法律依据→④用可留证方式送达（EMS/微信/邮件） |
| **工具** | 书面通知模板、EMS/微信/邮件 |
| **标准** | 4步全做完=通知有效 |
| **优先级** | P1 |
| **源神经元** | →N1（解除类型）+ N2（解除程序） |
| **不达标怎么办** | 缺解除权→先补权；缺送达证据→换快递 |
| **现场话术** | "发通知前先确认有没有解除权，有就用EMS发，留好回执" |

### 末梢2：收到对方解除通知应诉

| 字段 | 内容 |
|------|------|
| **触发词** | `收到通知|被解除|异议|要不要打官司` |
| **动作** | ①确认解除理由是否成立→②异议→尽快向法院起诉确认解除无效（有约定异议期从约定；无约定的实务中应在收到通知后尽快主张，拖延可能被认为接受解除）→③不异议→解除生效后计算返还金额 |
| **工具** | 起诉状模板、EMS送达回执 |
| **标准** | ⚠️待核：异议期间长短无统一规定（有约定从约定）；无约定的按"尽快起诉"掌握｜待合同编通则司法解释适用口径确认 |
| **优先级** | P1 |
| **源神经元** | →N2（解除程序）+ N6（解除权消灭） |
| **不达标怎么办** | 异议迟延可能被认定接受解除→转末梢3 计算返还，同时主张对方损失赔偿 |
| **现场话术** | "收到通知别拖，要么尽快起诉异议，要么抓紧算返还" |

### 末梢3：计算解除后返还金额

| 字段 | 内容 |
|------|------|
| **触发词** | `返还|退钱|折价|清算|结算` |
| **动作** | ①列已收款项→②列已付成本→③可返还→算差价→④不可返还（服务/劳务）→折价补偿→⑤加损失赔偿 |
| **工具** | 返还计算表 |
| **标准** | 返还+折价+赔偿，三方均结清 |
| **优先级** | P1 |
| **源神经元** | →N3（解除后果）+ N5（违约赔偿） |
| **不达标怎么办** | 算不出→临时仲裁或法院确定 |
| **现场话术** | "已付的钱能退就退，退不了就折价，有损失另算" |

### 末梢4：检查解除权是否过期

| 字段 | 内容 |
|------|------|
| **触发词** | `过期|还能不能解除|超过时间|时效` |
| **动作** | ①查合同有无约定行使期限→②有→是否超期→③无→自知道或应当知道解除事由起是否已超一年→④未超一年的，查对方有无催告→⑤催告后超过合理期限→解除权消灭 |
| **工具** | 合同原件、催告记录 |
| **标准** | 未过期→可继续；已过期→转其他救济 |
| **优先级** | P0（一票否决：过期了就不能解除） |
| **源神经元** | →N6（解除权消灭） |
| **不达标怎么办** | 解除权没了→走损害赔偿或其他救济途径 |
| **现场话术** | "先查解除权还在不在，不在就换路走" |
